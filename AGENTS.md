# RushB Public Website

Static HTML/CSS for the public domain, contact details and store/legal pages. Start with Git status, `CNAME`, the target HTML and its translations/store variants.

- Keep changes in the owning page and preserve shared navigation, app URLs and store verification files unless explicitly in scope. Check all affected visitors, viewport sizes and links.
- Track the authoritative legal copy, store variant and approval when terms or privacy text changes. Do not derive policy or change its claims from a design screenshot.
- Preview locally with `python3 -m http.server --bind 127.0.0.1 8080`; verify affected pages and links in a browser. Check unknown hosting assumptions before treating them as facts.
- Publishing, domain/DNS, external service changes, commits and pushes require explicit authorization.
