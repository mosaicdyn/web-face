How to practice nades in CS2

Unlimited grenades, a camera that shows where each nade lands and a key that repeats your last throw — set up in two minutes, offline or with friends.

Option 1: Practice mode, no console

CS2 has a practice server built in. It covers the basics in four clicks.

1

Open Play → Practice

In the main menu go to Play and open the Practice tab.

2

Turn on three options

Grenade Camera, Infinite Ammo and Infinite Warmup — the switches in the list on the left.

3

Pick a map

Choose the map you want to learn, for example Mirage or Inferno.

4

Press Go

You land on an empty server with unlimited nades and a camera that shows where each one lands.

Option 2: the practice config

Practice mode covers the basics. For a rethrow key, clearing smokes and full control, start an offline game, open the console with ~ and paste this config. If the console does not open, turn it on in Settings → Game → Enable Developer Console.

sv_cheats 1
sv_infinite_ammo 1
ammo_grenade_limit_total 5
sv_grenade_trajectory_prac_pipreview 1
sv_grenade_trajectory_prac_trailtime 8
mp_buy_anywhere 1
mp_buytime 9999
mp_freezetime 0
mp_roundtime_defuse 60
mp_warmup_end
bind n sv_rethrow_last_grenade

To load it with one command, save the lines as practice.cfg in the game/csgo/cfg folder of your CS2 install. Then type exec practice in the console.

Every nade practice command

All of these work only on your own server or in an offline match. They do nothing in Premier, Competitive or on FACEIT.

Binds for nade practice

Three keys save the most time: repeat the last grenade, clear the smokes and fly to the other side to check the result.

bind n "sv_rethrow_last_grenade"
bind m "ent_fire smokegrenade_projectile kill; stopsound"
bind k "noclip"

These binds need sv_cheats 1, so they only work offline. Binds that pick a grenade with one key are on our CS2 binds page.

Commands from old guides that no longer work

Many configs online were written for CS:GO. In CS2, sv_grenade_trajectory and sv_grenade_trajectory_time are gone: the grenade camera and sv_grenade_trajectory_prac_trailtime replace them. Some guides also list cl_grenadepreview — you don’t need it, the grenade camera already shows where the nade lands.

About jump-throw binds. Since the August 2024 update, binds that combine more than one movement or attack action (for example a jump-throw or null bind) no longer work on Valve servers. Valve made the jump-throw reliable without a bind: jump and release the grenade at the same time. A single-action bind such as bind mwheelup +jump is still fine.

A practice routine that works

  1. Learn the lineup first. Find the position, the aim point and the throw type — in RushB each lineup has a screenshot breakdown and a video.
  2. Throw it with the grenade camera on. Watch where it lands before you even release.
  3. Repeat it with the rethrow key and check it from the enemy side with noclip.
  4. Clear the smoke and throw it again by hand until it lands ten times in a row.
  5. Use it in deathmatch or a casual match before you count on it in Premier or on FACEIT.

Workshop maps for nade practice

The Steam Workshop has practice maps made for utility. Yprac Hub combines a nade trainer with aim and prefire drills. In Play → Practice you can also open the Workshop with the Map Guide filter and download a guide for the map you play; then turn on Use Map Guide before you start.

Practise with friends

On a private server the host — or anyone with RCON access — runs the config, and everyone on the server gets unlimited nades and the grenade camera. Agree on who throws and who watches from the other side: it is the fastest way to learn smokes for a full execute.

Questions

What is the command for infinite nades in CS2?

Type sv_cheats 1, then sv_infinite_ammo 1. Add ammo_grenade_limit_total 5 to carry every grenade type at once. It works on your own server or in an offline match.

How do I rethrow my last grenade?

Use sv_rethrow_last_grenade. Bind it to a key — bind n "sv_rethrow_last_grenade" — and the game throws the same grenade again from the same spot, even while you watch from somewhere else.

How do I clear smokes instantly?

With sv_cheats 1 on, ent_fire smokegrenade_projectile kill removes every smoke on the map. ent_remove_all inferno removes molotov fire.

How do I see where my grenade will land?

Turn on the grenade camera: sv_grenade_trajectory_prac_pipreview 1, or the Grenade Camera switch in Play → Practice. A small window shows the landing spot while you aim.

Can I use practice commands in Premier or on FACEIT?

No. They need sv_cheats 1, which only works on your own server or in an offline match.

Do I need a jump-throw bind to practise lineups?

No. Since August 2024 binds that combine several movement or attack actions don’t work on Valve servers, and the jump-throw is reliable without one: jump and release the grenade at the same moment.
